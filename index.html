Household

Only Wisconsin and Illinois are built into this tool today — Indiana, Michigan, South Carolina, and Florida are planned but not yet added (using any other state requires adding its rules to tax_tables.py first; see the repository README). Wisconsin taxes retirement-account withdrawals the same as wages; Illinois exempts Social Security, pensions, and 401k/IRA withdrawals from state tax entirely, taxing only wages at a flat 4.95%. If you plan to relocate before or during retirement, set these two differently — otherwise leave them the same.

Results, ranked by net-of-tax ending wealth

Net-of-tax wealth accounts for the fact that traditional dollars still owe ordinary income tax, and taxable-brokerage dollars still owe capital-gains tax — Roth, traditional, and taxable dollars are not worth the same amount, so summing them at face value would overstate traditional-heavy scenarios.
